`NE`/`NC` here is the **target** disposition; it is not a pass. **Evidence** uses only:

- `measured` — a passing automated native test covers the row (or the part named); each row says
  "no differential" unless the test compares against reference-derived output (the fixture
  goldens, the Codex/tool reference captures, or import equivalence against
  `fixtures/pi-sessions/*/requests.jsonl`), in which case it says "differential vs reference
  fixture". "measured (part)" and "gap:" record what the cited tests do not cover;
- `observed` — seen in the guarded native walkthrough or a recorded packaging run (`walk`, `pkg-ev`);
- `failed` — a recorded run missed the row's assertion;
- `unverified` — code exists, no test;
- `not started` — no native implementation (with the reason, e.g. `NP`, `BL`, reserved).

Owner: **Opus** = main implementation; **Codex** = reserved final integration.

# Brace expansion semantics

The native model-pattern brace expansion follows the brace-expansion 5.0.12 sequence
and alternative semantics used by minimatch 10.2.6, locked by the Pi reference at
`d2a311097cbcf669e699479587332ae3988a49d0`. Source:
https://github.com/juliangruber/brace-expansion.

The MIT notice is retained alongside this file and distributed with native packages.
No JavaScript package or runtime is shipped for this implementation. Native source:
`crates/pipkin-engine/src/runtime/models/pattern/braces.rs`.
